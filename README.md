# Eclipse

![Banner](https://img.shields.io/badge/Status-In%20Development-blue) ![Unity Version](https://img.shields.io/badge/Unity-6000.3.11f1-black?logo=unity)

**Eclipse** is a single-player, open-world medieval fantasy RPG set in a world that doesn't revolve around you. You are not the chosen hero, but simply another entity in a living universe where story arcs, faction conflicts, and world events unfold whether you are there to witness them or not.

Inspired by games like *Elden Ring* and *Chivalry 2*, Eclipse blends immersive worldbuilding, skill-based directional combat, and unscripted dynamic storytelling.

## Contributing

Contributions, issues, and feature requests are welcome! Whether you want to fix a bug, improve combat physics, or expand world lore, here is how you can help:

1. **Open an Issue:** If you encounter a bug, an unexpected physics behavior, or have a feature suggestion, please open an [Issue](https://github.com/LucHL/Eclipse/issues) with a clear description.
2. **Submit a Pull Request:**
   * Fork the repository.
   * Create your feature branch.
   * Commit your changes (`git commit -m 'feat: something'`).
   * Push to the branch (`git push origin feat/branch-name`).
   * Open a Pull Request against the main development branch.
